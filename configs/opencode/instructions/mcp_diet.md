# MCP diet and local documentation

Prefer an existing deterministic CLI plus a focused skill over another MCP. Keep MCP for interactive, stateful, semantic, or browser workflows. Capability checks must not read secrets.

Local documentation is served from the configured cache. Sources for Expo, React Native, Android Gradle Plugin, Compose, MikroORM, Vite, TanStack, Cloudflare, and Firebase may be refreshed by the bounded user-level updater; failures are reported and stale cached docs remain usable.
