## What I do
- Read the full TASK-XXX block (goal, in/out scope, criteria, verification, notes) before editing
- Make the smallest change that satisfies the acceptance criteria; do not expand scope
- Run the AGENTS.md verification commands and report back with the closing commit hash

## When to use me
Use this when a task in TASKS.md is the next thing to work on, or when the user hands you a TASK-XXX heading and expects implementation.
