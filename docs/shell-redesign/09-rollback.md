# 09 — Rollback

**Date:** 2026-07-31

How to restore a known-good state at any point.

---

## 1. Anchors

| Anchor | Meaning |
|---|---|
| `git checkout 97410e3` | Through M13 (wallpaper panel). Shell = redesigned (morph engine, panels, keybinds) |
| `git checkout 575442b` | Through M12 (Quick Share + LocalSend). Clean committed state before wallpaper panel |
| `git checkout 854ce15` | Through M10 (ScrollOverview adoption, QML Overview deleted) |
| `git checkout e883e4c` | Through M6/M7 (morph engine + state machine) |
| `git checkout 107c884` | Full pre-redesign baseline (original shell, QML overview, old keybinds) |
| `0dd17a0845a5009b048937f6366a467a3886823a` | Repo HEAD at baseline capture |

## 2. Rolling back the shell (QML + services)

```sh
# 1. Pick an anchor
git checkout <anchor>

# 2. Re-symlink the shell QML (repo → ~/.config/noxflow/shell)
make install-shell

# 3. Rebuild + reinstall the Rust binaries (noxd, noxctl)
make install-bin

# 4. Re-symlink systemd units
make install-systemd
systemctl --user daemon-reload

# 5. Restart the stack
systemctl --user restart noxd.service noxflow-shell.service

# 6. Verify
systemctl --user is-active noxd noxflow-shell
pgrep -ax quickshell        # expect exactly 1
```

## 3. Rolling back the Hyprland config

The live config symlinks into the repo (`~/.config/hypr/conf` → repo `hypr/conf`),
so a `git checkout` of the Lua files is instant. To restore the scroll-overview
binding to the old noxctl overview:

```sh
git checkout <anchor> -- hypr/conf/40-binds-launch.lua hypr/conf/95-plugins.lua hypr/hyprland.lua
hyprctl reload
```

## 4. Disabling the scroll-overview plugin (if it misbehaves)

```sh
hyprpm disable scrolloverview      # or: hyprctl plugin unload <path>.so
hyprctl reload
# 95-plugins.lua auto-falls back to super-tab-overview.sh (legacy script)
```

## 5. Restoring the old QML Overview (pre-M10)

```sh
git checkout 854ce15 -- shell/noxflow/surfaces/overview/
git checkout 854ce15 -- shell/noxflow/shell.qml shell/noxflow/core/
git checkout 854ce15 -- hypr/conf/40-binds-launch.lua hypr/scripts/super-tab-overview.sh
make install-shell
systemctl --user restart noxflow-shell.service
```

## 6. Restoring the original startup race fix (pre-M3)

If the dual-shell issue was never actually present on your setup and you want
`panel-switch.sh show` back in startup.sh:

```sh
git checkout 107c884 -- hypr/scripts/startup.sh
```

## 8. Emergency recovery

If the shell fails to start and leaves you without a bar:

```sh
# 1. Stop the shell (systemd will retry; stop it to break the loop)
systemctl --user stop noxflow-shell.service

# 2. The fallback service (Wayle) exists but is masked — unmask it temporarily
#    only if you need a UI: (Wayle is NOT recommended; it's the legacy shell)
# systemctl --user unmask wayle.service && systemctl --user start wayle.service

# 3. Better: fix the shell instead
journalctl --user -u noxflow-shell -n 80 --no-pager   # read the error
git checkout 575442b                                   # last known-good
make install-shell && systemctl --user restart noxflow-shell.service
```

> **Wayle is a safe-mode fallback, not the default.** `noxflow-fallback.service`
> has no `[Install]` section (2026-07-31) — it fires only via
> `OnFailure=noxflow-shell.service` (genuine crash). Wayle can be started
> manually with `panel-switch.sh wayle` but will never auto-start at login.
> Unmask/start it only in a genuine emergency.

## 9. Data preserved during rollback

- `~/.local/state/noxflow/` (workspace names, minimized windows, clipboard) — never touched by rollback
- `~/.cache/hypr/` (theme colors, generated configs) — regenerated by theme-pass.sh
- `settings/state.local.json` (gitignored) — unaffected
