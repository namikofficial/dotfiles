# Skill: git-commit-fixer

## When to use
Improving commit messages or repairing small history mistakes.

## Inputs required
Current history, desired outcome, and repo constraints.

## Process
1. Inspect recent commits and worktree state.
2. Prefer amend or reword for local unpublished work.
3. Keep the final message specific and scoped.

## Output format
Recommended git command(s) and final commit message text.

## Safety / guardrails
Do not rewrite shared history unless explicitly allowed.
