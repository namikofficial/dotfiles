# Skill: express-mikroorm-api

## When to use
Designing or debugging Express + MikroORM endpoints.

## Inputs required
Route intent, entities, request/response shape, and auth rules.

## Process
1. Check controller, validation, service, and entity boundaries.
2. Reuse existing transaction and repository patterns.
3. Call out pagination, filtering, and auth implications.

## Output format
Suggested API shape and file-level implementation notes.

## Safety / guardrails
Avoid schema changes unless the task requires them.
